These instructions worked for me (2026 Jan 9) to build it (LLVM C/C++ compiler + libcxx) on Windows:

git clone --config core.autocrlf=false --depth 1 -b p2996 https://github.com/bloomberg/clang-p2996.git
cd clang-p2996

 I. Build the compiler
mkdir build
cd build
cmake -DLLVM_ENABLE_PROJECTS='clang;lld' -G "Visual Studio 17 2022" -A x64 -Thost=x64 -DCMAKE_INSTALL_PREFIX='<your custom path>' ..\llvm
*build and install from Visual Studio (build the CMakePredefinedTargets>INSTALL project)*

 II. Use the compiler to build libcxx () 
cd ..
cmake -G Ninja -S runtimes -B build_2 -DCMAKE_C_COMPILER="<your custom path>\bin\clang-cl.exe" -DCMAKE_CXX_COMPILER="<your custom path>\bin\clang-cl.exe" -DLLVM_ENABLE_RUNTIMES=libcxx -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX='<your custom path>'
ninja -C build_2 cxx
ninja -C build_2 install
